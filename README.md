# IntelliFinance

Front-end Next.js application for IntelliFinance — a production-quality UI for financial analytics and explainable AI research.

This repository contains a TypeScript + Next.js (App Router) frontend scaffold with Tailwind CSS and mock data for demonstrations.

Run locally:

1. yarn (or npm install)
2. yarn dev

This is a front-end scaffold only. No backend or live data is included. All data in /data/mock.ts is demo research data and not market information.
